# ไฟล์ออกแบบ

ไฟล์ทำงานของแคนวาส — ตอนนี้เหลือแค่เรื่องเดียว: **hero ที่ใส่รูปเข้าไป**
ส่วนอื่นของเว็บใช้ของเดิมตามที่ deploy อยู่ ไม่ได้แก้

สไตล์ในไฟล์เหล่านี้ลอกมาจาก `app/globals.css` ตัวจริง (`_base.txt` คือ token ชุดเดียวกัน)
เพื่อไม่ให้แคนวาสกับเว็บจริงหลุดจากกัน

- `HeroBefore.dc.html` — hero ที่ใช้อยู่ตอนนี้ ไว้เทียบก่อน-หลัง
- `Main.dc.html` — **แบบ A** รูปเต็มพื้นหลัง + scrim (หน้าเต็ม) · มี tweak `Scrim` ลากปรับระยะได้
- `HeroCard.dc.html` — **แบบ B** รูปเข้าไปนั่งในการ์ดที่แผงสต็อกเคยอยู่
- `HomeMobile.dc.html` — แบบ A บนจอ 390px
- `canvas.json` — ผังการวาง · `_base.txt` — token จาก globals.css

`hero-wide.jpg` / `hero-tall.jpg` เป็นรูปที่บีบมาสำหรับแคนวาสโดยเฉพาะ (900px / 62KB
เพราะแคนวาสฝังรูปเป็น base64 มีเพดาน) **ไม่ใช่ไฟล์สำหรับเอาไปใช้จริง** —
ของจริงต้อง gen ที่ ≥2400px แล้วทำเป็น AVIF หลายขนาด

ไฟล์ `medequiploan-redesign.html` ที่ได้จากการ seed ไม่ได้ commit ไว้ (2.8 MB)
